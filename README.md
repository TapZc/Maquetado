# Maquetación Web Semántica y Responsive Design

Proyecto web desarrollado con **HTML5 semántico** y **CSS3**, aplicando principios de maquetación limpia, **CSS Grid** y **Media Queries** para lograr un diseño totalmente adaptativo.

---

## Requisitos Cumplidos

1. **Etiquetas Semánticas HTML5:**
   - `<header>`: Encabezado principal y logotipo.
   - `<nav>`: Menú de navegación.
   - `<main>`: Contenedor del contenido principal.
   - `<section>` y `<article>`: Agrupación semántica de los servicios/tarjetas.
   - `<footer>`: Pie de página con créditos.

2. **Layout Adaptativo (Grid & Media Queries):**
   -  **Móvil (< 600px):** 1 columna.
   -  **Tablet (600px - 899px):** 2 columnas (`grid-template-columns: repeat(2, 1fr)`).
   -  **Escritorio (≥ 900px):** 3 columnas (`grid-template-columns: repeat(3, 1fr)`).

3. **Estilos y Box Model:**
   - Definición de tipografía moderna (**Plus Jakarta Sans**).
   - Uso de variables CSS para paleta de colores.
   - Aplicación de `padding`, `margin`, `border-radius` y sombras `box-shadow` suaves.

---

##  Archivos del Proyecto

- `index.html`: Estructura del documento.
- `estilos.css`: Estilos visuales y reglas de responsividad.
